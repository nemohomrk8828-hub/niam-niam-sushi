# Niam Niam Sushi – svetainė

Tai paprasta vieno puslapio svetainė. Nereikia serverio, duomenų bazės ar mokamų įskiepių.

## Kaip įkelti į GitHub

1. Sukurk GitHub paskyrą arba prisijunk.
2. Sukurk naują **Public** repozitoriją, pavadinimu `niam-niam-sushi`.
3. Įkelk visus šio aplanko failus ir `images` aplanką (ne vien ZIP archyvą).
4. Repozitorijoje atidaryk **Settings → Pages**.
5. Prie **Build and deployment** pasirink **Deploy from a branch**.
6. Branch pasirink `main`, aplankas `/ (root)`, tada spausk **Save**.
7. Palauk, kol GitHub Pages paskelbs svetainę. Nuoroda atsiras tame pačiame Pages puslapyje.

## Kaip įdėti nuotraukas

Į aplanką `images` įkelk savo nuotraukas tiksliai šiais vardais:
- `hero.jpg` – pagrindinė didelė nuotrauka viršuje;
- `sushi-1.jpg`;
- `sushi-2.jpg`;
- `sushi-3.jpg`.

Jei nuotraukos yra PNG, pakeisk plėtinį ir atitinkamą kelią `index.html` / `style.css`, arba išsaugok JPG formatu.

## Kaip pakeisti informaciją

Atidaryk `index.html` ir pakeisk tekstus. Telefono numeris naudojamas skambinimo ir WhatsApp nuorodose.

## Svarbu prieš viešinant

Patikrinkite restorano telefono numerį, adresą ir darbo laiką. Ketvirtadienio laiką įrašiau kaip 10:00–21:00, nes pateiktame tekste buvo „10:00:21:00“.
