# Niam Niam Sushi website

Static, responsive one-page website. No server, database, or paid plugin required.

## GitHub Pages update
Upload the contents of this folder to the root of the existing `niam-niam-sushi` repository, replacing `index.html`, `style.css`, and `script.js`. Upload the `images` folder too; it contains `hero.jpg`.

Keep `index.html` at the repository root. Then commit the changes. GitHub Pages will redeploy automatically.

The menu currently lists the requested categories. Dish names, descriptions, prices, and individual restaurant photos should be filled from the restaurant's original menu PDFs and photo collection; they are intentionally not invented here.
